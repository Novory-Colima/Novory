# Introducción

Este documento representa la lista oficial de verificación para el desarrollo de cualquier proyecto bajo los estándares de Novory.

Su objetivo es garantizar que cada sitio web mantenga la misma calidad técnica, visual, narrativa y estratégica definida en el Documento Maestro.

Ningún proyecto deberá considerarse finalizado sin haber completado este checklist.
